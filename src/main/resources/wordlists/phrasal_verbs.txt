# Tokenizer.groupPhrasalVerbs groups a tappable word with a following particle only when the
# pair is listed here. The old rule grouped ANY tappable word followed by a particle-looking
# word — so "book" before "on" in "book on the table" highlighted as if it were a phrasal verb,
# because the check never looked at what came before the particle. A whitelist fixes that: an
# ordinary noun in front of "on"/"in"/"over" simply is not in this list, so it stays ungrouped.

# are matched loosely (regular endings and a short irregular-verb table), so one base-form line
